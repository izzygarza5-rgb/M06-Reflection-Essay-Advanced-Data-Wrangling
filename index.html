Used to combine two datasets based on a shared key, keeping all rows from the first dataset. ```{r} library(dplyr) df1 <- data.frame(id = c(1,2,3), name = c("A","B","C")) df2 <- data.frame(id = c(1,2,4), score = c(90,85,88)) left_join(df1, df2, by = "id") ``` > 2\. `inner_join()` > > When to use: > > - Combines two datasets but keeps only matching rows in both tables. ```{r} inner_join(df1, df2, by = "id") ``` > 3\. `mutate()` > > When to use: > > - Used to create or modify variables in a dataset. ```{r} data <- data.frame(price = c(10,20,30)) data %>% mutate(tax = price * 0.1) ``` # **What I liked most about wrangling tools** -
